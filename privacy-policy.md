A aplicação Mike Optidata, para fornecer os seus serviços de automação via WhatsApp, requer acesso para ler e enviar mensagens em nome do utilizador através da API Oficial do WhatsApp. Nenhuma informação pessoal ou de conversas é partilhada com terceiros. Os dados são processados com o único propósito de executar as automações solicitadas pelo utilizador.
